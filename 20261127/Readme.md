# Crear Joc Sorpresa

1. Descarrega el [ZIP](https://github.com/mikibardaji/DAW_EXERCICIS_ALUMNES/raw/refs/heads/main/20261127/JuegoSorpresa.zip) del projecte.
2. Descomprimeix el fitxer ZIP.
3. Dins la carpeta del projecte, busca la carpeta `dist`, entra a la carpeta `javadoc` i obre el fitxer `index.html`.
4. Allà, accedeix a l'apartat **`MetodosJuego`**, on estan explicats un per un tots els mètodes que has d'implementar.
5. Obre **NetBeans**, ves a **File > Open Project...**, busca la carpeta descomprimida i obre el projecte.
6. Implementa les funcions una per una a `MetodosJuego.java` i escriu línies de codi al `main` (a `JuegoSorpresa.java`) per provar-les individualment.
7. Quan les hagis implementat i provat totes, comenta les línies de prova del `main` i desenvolupa la lògica completa del joc (crea les variables pertinents, els condicionals necessaris i ves cridant a cadascuna de les funcions).
