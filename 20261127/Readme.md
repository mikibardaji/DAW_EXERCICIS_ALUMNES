# Crear Joc Sorpresa

1. Descarrega el <a href="[JuegoSorpresa.zip](https://github.com/mikibardaji/DAW_EXERCICIS_ALUMNES/raw/main/20261127/JuegoSorpresa.zip)" download>ZIP</a> del projecte.
2. Descomprimeix el fitxer ZIP.
3. Dins la carpeta del projecte, busca la carpeta `dist`, entra a la carpeta `javadoc` i obre el fitxer `index.html`.
4. Allà, accedeix a l'apartat **`MetodosJuego`**, on estan explicats un per un tots els mètodes que has d'implementar.
5. Al `main` del projecte, escriu alguna línia de codi per provar cadascun dels mètodes.
6. Quan els hagis implementat i provat individualment, comenta les línies de prova del `main` i desenvolupa el joc (crea les variables pertinents, els condicionals necessaris i ves cridant a cadascuna de les funcions).
